# PlotBoard

A real-time collaborative whiteboard app create boards, invite others, and see each other's changes live.

## Features

- Google or manual sign-up/login
- Create and manage multiple whiteboards
- Invite collaborators via email with Owner / Editor / Viewer roles
- Draw and edit shapes (rectangles, circles, arrows, text) on a shared canvas
- Real-time sync across all connected members no refresh needed

## Tech Stack

**Backend:** Node.js, TypeScript, Express, Socket.io, Supabase (Auth, Database)
**Frontend:** React, TypeScript, Vite, Canvas API
